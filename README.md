# TaskFlow

TaskFlow is a full-stack MVP for projects, configurable Kanban workflows, and
real-time task updates. Start the complete stack with:

```sh
cp .env.example .env
docker compose up --build
```

The UI is available at <http://localhost:8081>. See
[docs/README.md](docs/README.md) for credentials, API endpoints, architecture,
tests, and troubleshooting.
